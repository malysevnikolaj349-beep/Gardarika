## 2024-05-22 - Improved Bot Onboarding Context
**Learning:** Users making irreversible choices (like Class or Faction) in a chat interface need context *immediately before* the decision buttons, not in a separate help menu.
**Action:** When designing selection flows, always prepend the selection message with short descriptions of the available options.

## 2024-05-22 - Visual Hierarchy in Text Interfaces
**Learning:** Using emojis as icons and bold text for labels significantly improves the scannability of dense information (like a character profile) in a text-only interface.
**Action:** Use a consistent emoji set for attributes and headers to create a visual language within the text.
